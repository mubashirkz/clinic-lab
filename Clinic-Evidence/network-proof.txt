--- Analysis: Proof traffic cannot leave lab ---
enp0s3 (192.168.50.0/24) = Host-Only Adapter vboxnet0
- No default gateway on this subnet
- Traffic on 192.168.50.10 stays between VM <-> Host only
- No route to internet from this subnet

enp0s8 (10.0.3.0/24) = NAT Adapter for management only (git push)
- Default route via 10.0.3.2 for internet
- Lab app DOES NOT bind to this interface
- clinic_app.py binds to 192.168.50.10 / 127.0.0.1 only

Conclusion: Lab app traffic cannot leave the lab because it binds to Host-Only IP. 
Only management traffic uses NAT. All work occurs in this lab or on authorized systems.
